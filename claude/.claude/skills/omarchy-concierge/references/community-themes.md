# Omarchy Community Themes

Community themes installable via `omarchy-theme-install <git-url>`.

> **Install:** `omarchy-theme-install https://github.com/user/repo`
> **Update all:** `omarchy-theme-update`
> **Remove:** `omarchy-theme-remove`
> **Official catalog:** https://manuals.omamix.org/2/the-omarchy-manual/90/extra-themes

## How to Discover New Themes

### GitHub Search

```bash
# By stars (most popular)
curl -s "https://api.github.com/search/repositories?q=omarchy+theme&sort=stars&per_page=30"

# By recently updated
curl -s "https://api.github.com/search/repositories?q=omarchy+theme&sort=updated&per_page=30"

# By recently created
curl -s "https://api.github.com/search/repositories?q=omarchy+theme&sort=stars&order=desc&per_page=30"
```

### Official Sources

- **Extra Themes page:** https://manuals.omamix.org/2/the-omarchy-manual/90/extra-themes
- **Omarchy Discord:** Community shares new themes regularly
- **awesome-omarchy:** https://github.com/Wheel-Smith/awesome-omarchy

### Theme Creation Tools

- **Aether:** https://github.com/bjarneo/aether — Create themes the easy way
- **Tēma:** https://github.com/bjarneo/tema — TUI theme creation tool
- **Peachy:** https://github.com/bjarneo/peachy — Generate color themes from images
- **Theme Builder:** https://github.com/gitcoder89431/omarchy-theme-builder — Interactive real-time builder
